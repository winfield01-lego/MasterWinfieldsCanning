# Canned Goods Pantry

A mobile-friendly, browser-based canned goods inventory app designed for GitHub Pages.

## Features
- Canned goods inventory with food, jar size, method, quantity, date, location, notes
- Automatic 18+ month aging flag
- Search and age filters
- Community request queue with statuses
- Empty jar, lid, and ring inventory
- Dashboard metrics
- Local browser storage
- JSON export/import for backups and moving data between devices

## GitHub Pages
Create a GitHub repository, upload `index.html`, then go to **Settings → Pages** and deploy from the `main` branch/root.
